# 主试逐字稿与操作员检查表（正式实验）

> 用法：主试按 §1 逐字念；操作员按 §2 勾选。实验全程保持中性，不引导被试评价我们的工具。

## 1. 逐字稿

### 1.1 开场（0:00–0:05）

「你好，谢谢你今天来参加。我是 [名字]，这位是 [名字]，今天由我们来带你完成这个实验。」

「这是一个课程研究，想了解弹幕会怎么影响观看体验，以及不同的弹幕过滤方式会带来什么差别。整个过程大约 75 分钟。」

「先说几件重要的事：第一，参加完全自愿，任何时候都可以停下来或者退出，不会有任何问题，报酬照付。第二，我们不会记录你的 B 站账号、用户名或者任何身份信息，问卷上只有编号。第三，有些视频的弹幕里可能有攻击性或者剧透的内容，如果你觉得不舒服，随时告诉我。」

「这是知情同意书，请你看一下，有问题现在问我；没问题的话在这里签名。」

（被试签署后）「谢谢。先填一份背景问卷，大约 7 分钟。」

### 1.2 设备与练习（0:12–0:20）

「接下来我演示一下怎么操作。这是一个练习视频，只有 1 分钟。」

「你看，弹幕在这里（指屏幕）。这一组弹幕里，有些被隐藏了，有些被折叠成『已折叠·剧透』这样的占位，点一下可以展开原文。如果你觉得某条被判断错了，可以点『改标签』，把它改成你认为的类型，系统会记住。」

「正式实验时，你只需要像平常一样看视频，然后回答问卷。看的时候可以随时把想法说出来，比如『这条好烦』『这条挺有用』，说不说都可以。」

「有一点要说明：这个工具可能会犯错，可能藏了你不想藏的，也可能没藏你想藏的。这很正常，我们就是想看真实情况下它表现如何。你不用替它掩饰。」

### 1.3 每个条件开始前（重复 3 次）

「接下来是第 [1/2/3] 组，两组视频。这一组的弹幕状态和上一组可能不一样，具体怎么不一样我们最后再解释，你先按平常的方式看就行。」

「每支视频结束后，我会暂停，请你填一份短问卷，大约 3–4 分钟，然后我们看下一支。」

（C 条件额外）「这一组你可以试试点开折叠的弹幕，或者改一条标签，看看顺不顺手。用不用都行。」

### 1.4 休息（0:36–0:40）

「我们休息 3 分钟，你可以喝口水、去洗手间。休息期间我们先不聊刚才的内容，等全部结束再一起聊。」

### 1.5 访谈（0:58–1:08）

「最后聊几个问题，没有标准答案，怎么想就怎么说。」

1. 「三组里面，哪一组你看着最舒服？为什么？」
2. 「有没有哪条弹幕，你觉得不该被藏起来却被藏了？或者该藏没藏？可以指着屏幕说。」
3. 「剧透那种『折叠起来、点开能看』和直接消失，你更能接受哪种？为什么？」
4. 「你信任它自动帮你做决定吗？如果它判断错了，你会怎么办？」
5. 「如果明天就能装上，你会用吗？你会怎么设置它？」
6. 「你觉得『按类型过滤』和『按关键词过滤』，最大的差别在哪？」

（追问技巧：被试说「挺好的」时追问「哪里好？」；说「不准」时追问「举个具体例子」。）

### 1.6 结束（1:08–1:15）

「今天到这里，非常感谢。简单说明一下：三组分别是——A 全部弹幕、B B 站自带关键词屏蔽、C 我们的按类型过滤。我们想比较的是，光靠关键词够不够，以及按语义类型过滤能不能既减少不适又不丢信息。」

「这是你的报酬，请收好。如果之后你不想让我们用你的数据，可以随时联系 [邮箱] 撤回。」

「最后确认一下：你的问卷、日志我们都用编号保存，没有你的名字。谢谢你！」

## 3. 故障处理

| 现象 | 处理 |
|---|---|
| 弹幕完全没变化（C 条件） | 先看控制台 `__dmfFilter.state.diag`：intercepts 是否为 0；为 0 说明没拦到请求 → 刷新页面重试；仍为 0 则跳过该条件并记录 |
| 服务没起来 | `curl 127.0.0.1:8765/api/v1/health`；重启 `python3 -m danmaku_filter.cli serve --online-backend linear`；重启期间脚本 fail-open，弹幕照常显示 |
| 页面很卡 | 关闭其他标签页；确认密度控制为关；仍卡则降低视频清晰度 |
| 被试明显不适 | 立即暂停，询问是否继续；可跳过该条件或结束，报酬照付 |
| 视频不可用（下架/地区限制） | 用备选视频（stimuli.json 的 backup 字段）；记录替换 |
| 日志没导出 | 用 `copy(JSON.stringify(__dmfFilter.study.export()))` 手动复制到文件，标注 manual |
