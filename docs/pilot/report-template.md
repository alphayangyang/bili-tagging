# Pilot Study — Results (fill in after the sessions)

## Aim

The pilot tested (a) whether two coders can apply the eight-label taxonomy to real
danmaku consistently, and (b) whether viewers can install and use the filtering
plugin in a realistic video session, before the main study.

## Participants

- Coders: [2] group members (age, gender optional), no prior taxonomy training beyond the coding guide.
- Viewers: [2–3] group members; each used their own Bilibili account and a desktop browser.

## Materials

- 120 danmaku stratified-sampled from one music video ([BV id]); two blind coder sheets.
- Plugin userscript (Tampermonkey) with default preferences; one 10–15 minute video.
- Post-task survey (8 items) and server-side decision/correction logs.

## Procedure

Coders read the one-page guide, coded independently (~40–60 min). Viewers installed
the script, watched one video, then completed the survey. No discussion before both
coder sheets were saved.

## Limitations

- Small convenience sample (n=2 coders, n=2–3 viewers); no effect test, no randomisation.
- Single video; attack/conflict under-represented, so those labels were only checked on constructed examples.
- Coders were group members, not independent raters; kappa is an upper bound.
