## B. 每个视频块结束后（约 3–4 分钟）

**B0 主试填写**：participant、condition（A/B/C）、video（bvid）、genre（information/entertainment）、density（low/high）、block_order。

**B1 之前看过这个视频吗？** 没看过 / 看过片段 / 看过完整

**B2 不适感**（7 点）

1. 这段弹幕让我感到不适。
2. 这段弹幕让我觉得被冒犯。
3. 这段弹幕让我烦躁。
4. 看这段时我想把弹幕关掉。
5. 这段弹幕影响了我看视频内容。

**B3 共看感**（7 点）

1. 看这段时我感觉像和其他观众一起看。
2. 弹幕里的反应让我有共鸣。
3. 这段的弹幕氛围是友好的。

**B4 控制感**（7 点）

1. 我能控制自己看到哪些弹幕。
2. 过滤结果符合我的预期。
3. 如果一条弹幕被隐藏，我知道怎么找回来。

**B5 FOMO**（7 点 + 开放）

1. 我担心自己错过了有用的信息。
2. 如果担心，你担心错过的是什么？（一句话，可留空）__________

**B6 NASA-TLX**（每项 1–7，1 = 很低，7 = 很高）

1. 脑力需求：刚才需要多少思考/注意力？
2. 体力需求：刚才有多累（眼睛、操作）？
3. 时间压力：刚才节奏有多赶？
4. 绩效：你觉得自己看得有多好？（1 = 很差，7 = 很好）
5. 努力程度：为了看清/看懂，你花了多大力气？
6. 挫败感：刚才有多烦躁/受挫？

**B7 理解测验**（仅信息型视频，5 题单选 + 1 题自由回忆）

由主试按视频内容出题，题干与选项事先准备好（见 stimuli 清单的 comprehension 字段）。

自由回忆：「请用一两句话说出这个视频讲了什么。」（主试记录关键词命中数 0–5）

**B8 可解释性**（仅 C 条件）

1. 你能说出为什么某条弹幕被隐藏/折叠吗？ 能 / 不能
2. 你觉得给出的理由清楚吗？（1–7）
3. 举一个你觉得「判断错了」的例子（可留空）：__________

**B9 总体评价**（7 点）

1. 我愿意在这种弹幕状态下继续看视频。
2. 我会把这个工具推荐给朋友。
