# 模拟运行结果（S2 dry run，AI 被试，非人类数据）

> 状态：2026-11-19（v2：加 sham 条件 D + 盲化材料）。数据来自 8 个 LLM 子智能体模拟被试（P01 … P08），
> 每人的每块作答见 `data/study/agents/out/`，组装与分析的输入见 `data/study/questionnaire.csv` 与 `data/study/raw/`。
> **这不是人类被试数据**，只能用于管线验证、设计检查与 IMR 的示意性结果；对外提交时必须标注 simulated。

## 1. 这一版改了什么

1. **加 sham 条件 D**：面板、整池加载进度、折叠记录都在，但**什么都不过滤**（全 show）。这样
   A vs D 分离「界面/期待效应」，D vs C 分离「语义过滤的净效应」。
2. **盲化材料**：材料不再写条件名、不再写「这一组会过滤什么」，只写被试可见的事实（有没有面板与进度胶囊、
   池量、实际可见条数、面板统计的显示/折叠/隐藏），也不列出被隐藏弹幕的原文。被试无法从材料推断组别。
3. **8 个 AI 被试 × 6 块 = 48 blocks**：每人看全部 6 支视频一次；每人条件多重集 {A,A,B,B,C,D}，
   按拉丁方轮转（shift = (p−1) mod 4）。可验证：每条件 12 块、每个（视频,条件）单元恰好 2 次、每视频 8 次。
4. **新增两题期待/信任**（expectancy 1–2，1–7），既回应「安慰剂」质疑，也可当协变量。
5. 分析脚本扩到 4 条件、6 个计划对比（C−A、C−B、C−D、D−A、D−B、B−A），Holm 对 6 个校正。

## 4. 关键发现：盲化之后，不适感的差异消失

上一版（未盲化、3 条件、6 人）里 C 的不适感 2.63 明显低于 A 3.65、差异 −1.02；这一版材料盲化后
**不适感平了**（3.00 / 3.03 / 2.95 / 3.13，Holm 后所有对比 1.000）。同时控制感与期待/信任仍然
C > D > A/B：

- 控制感：C 3.75 > D 3.28 > A 2.42 / B 2.33（C−A、C−B 原始 p = .025，Holm 后 .148；n=8 不显著）；
- 期待/信任：C 3.58 > D 2.62 > A 2.12 / B 2.17（C−A 原始 p = .012，Holm 后 .070）。

判读：上一版的「不适感下降」很可能主要是需求特征（材料直接告诉被试这一组挡了多少条），而不是过滤本身；
盲化后只剩「有面板 + 确实挡了东西」带来的控制感与信任上升，而 sham（有面板但不挡）只拿到其中一部分
（C > D 方向一致但不显著）。这正是加 D 想回答的问题，也说明真人实验必须盲化材料与口头说明。

交互行为（48 块合计）：改标签纠正 0 次、恢复显示 3 次、展开折叠 0 次、改偏好 13 次。

## 7. 标注器效度（去泄漏口径）

120 条人工金标（`data/study/gold_v2.jsonl`，`other` 已按「必须有功能才给低分」重判）上，
在**剔除金标文本**的训练集上重训后（`scripts/f1_eval.py --labeled data/study/teacher_v4.jsonl
--gold data/study/gold_v2.jsonl`）：

- dominant 一致率 **0.525**，macro-F1 **0.350**（95% CI [0.255, 0.430]），weighted F1 0.509，家族级 0.437；
- 逐标签 F1：information .615、humor .431、conflict .364、emotional resonance .250、
  irrelevant repetition .250、other .177、attack 0（金标 6 条全未召回）；
- 二分类「该不该折叠/隐藏」：precision 0.38、recall 0.17、F1 0.286。

注意：analyze.py 的 RQ2 gold 表读的是 `data/study/models/` 里随包发布的模型，它们在训练池与金标有重叠，
数字偏高（.558 / .496）。IMR 里引用的是上面这组**去泄漏**数字。

## 8. 结论（能给课程报告用的部分）

1. 管线通了：48 块材料 → 8 个被试 → 组装 → 分析 → 表/图，一条命令可重建（见 §9 与 agents/README.md）。
2. 盲化 + sham 的设计价值被这条管线证明：未盲化时 C 的不适感优势在盲化后消失，说明原来的差异大概率是需求特征。
3. 模拟数据**不能当证据**：n=8、被试不真看视频、评分被材料里的计数锚定、人格是设定值。
4. 真实验只需要换输入：真人填 `data/study/questionnaire.csv` + 真人 session JSON，`analyze.py` 不用改；
   N=16、每条件 2 块（8 块/人）时 Wilcoxon 才可能达到显著。

## 10. 局限（写进论文限制段）

- 被试是 LLM 智能体，不是人：没有真实视觉注意、没有真实情绪反应，量表锚定依赖文字材料。
- 8 个人格是人为设定的点，方差比真人小，效应量不可外推。
- 理解测验退化为自评（comp 1–5 为子项自评），不能替代内容 MCQ。
- 低密度抽稀不在面板统计里（设计如此），有被试注意到「少了 541 条但面板显示 0/0」并因此降低控制感与信任；
  真人实验里这是需要在主试脚本中说明的界面细节。
- 标注器去泄漏后 macro-F1 0.350，意味着 C 条件的过滤本身有相当多误判，真人实验里要一并报告。
