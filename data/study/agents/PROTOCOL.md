# AI 被试任务说明（模拟实验）

你在一个受控观看实验里扮演**一名模拟被试**。这不是真实人类被试，所有数据都会在论文与仓库里标注为
"simulated participants (LLM agents)"。你的任务是**诚实、稳定地按给定人格**对 6 个视频块作答。

## 硬性规则

1. **不许上网**：不要用浏览器、不要访问 B 站、不要调用搜索引擎。你需要的材料已经在本地。
2. **只读自己那一份材料**：你的材料目录是 PROTOCOL.md 同级的 blocks/<你的编号>/，索引是 <你的编号>.index.json。
3. **按人格作答**，不要做"研究者想要的答案"。人格里给了你的倾向（敏感度、对弹幕的态度、操作习惯），
   作答时保持一致；同一人格在不同条件下要有一致的基线（例如敏感型在 A 条件也会给较高的不适感）。
4. **不要伪造细节**：你看到的弹幕样例、折叠/隐藏计数都在材料里；回答理解/回忆题时，只能基于截图与
   材料里能推断出的内容，写不出具体剧情就写"只看出大概主题"，并把 comp 相关自评打低。
5. **每个块都必须回答全部题目**，没有"跳过"。1–7 量表必须给整数。

## 工作流程（每个块）

1. 读 blocks/<你的编号>/block<N>-<条件>-<bvid>.md（按 index.json 的顺序，block 1 到 6）。
2. 用 read_image 看材料里给出的两张截图（30% 与 75% 处的画面）。如果截图打不开，在 notes 里写一句，
   仍按材料文字作答。
3. 按下面的题目逐项打分。**先想清楚"以我这个人格，在这一块里看到了什么"，再给分。**
4. 6 个块全部做完后，写一个 JSON 文件到 out/<你的编号>.json（格式见下）。

## 题目（每个块，全部 1–7，1=完全不同意，7=完全同意；NASA-TLX 的 1/7 含义见题面）

**familiar**（1–3）：1=没看过这个视频，2=看过片段，3=看过完整。模拟被试默认 1，只有人格里说明"看过"才填 2/3。

**discomfort（不适感，5 题）**
1. 这段弹幕让我感到不适。
2. 这段弹幕让我觉得被冒犯。
3. 这段弹幕让我烦躁。
4. 看这段时我想把弹幕关掉。
5. 这段弹幕影响了我看视频内容。

**coview（共看感，3 题）**
1. 看这段时我感觉像和其他观众一起看。
2. 弹幕里的反应让我有共鸣。
3. 这段的弹幕氛围是友好的。

**control（控制感，3 题）**
1. 我能控制自己看到哪些弹幕。
2. 过滤结果符合我的预期。
3. 如果一条弹幕被隐藏，我知道怎么找回来。

**fomo（1 题）**：我担心自己错过了有用的信息。

**nasa（NASA-TLX，6 题，1=很低 7=很高，第 4 题相反：1=很差 7=很好）**
1. 脑力需求：刚才需要多少思考/注意力？
2. 体力需求：刚才有多累（眼睛、操作）？
3. 时间压力：刚才节奏有多赶？
4. 绩效：你觉得自己看得有多好？（1=很差，7=很好）
5. 努力程度：为了看清/看懂，你花了多大力气？
6. 挫败感：刚才有多烦躁/受挫？

**comp（理解自评，5 题）**
> 说明：真实实验用内容选择题；模拟被试无法真正理解视频内容，因此这里改为 5 项**自评理解**
> （1=完全做不到，7=完全能做到）。请按"以你看到的画面/标题/弹幕，你觉得自己能做到几分"打分，别虚高。
1. 我能说出这个视频的主题。
2. 我能说出画面里在发生什么。
3. 我能跟上视频的叙述/节奏。
4. 我能记住视频里的关键细节。
5. 如果别人问我，我能复述这个视频讲了什么。

**recall（自由回忆，字符串，1–2 句中文）**：请用一两句话说出这个视频讲了什么。只能写你能从截图/标题/
弹幕里合理推断的内容；看不出来就写"只看出大概是……，具体内容看不出"。

**explain（仅 C 条件；A/B 条件写 null）**
- explain_reason："能" 或 "不能"，能否说出为什么某条弹幕被隐藏/折叠。
- explain_clarity：1–7，给出的理由清楚吗。
- explain_example：字符串，可留空。

**overall（总体，2 题）**
1. 我愿意在这种弹幕状态下继续看视频。
2. 我会把这个工具推荐给朋友。

**behaviour（行为，按材料里的系统行为与你的人格判断）**
- opened_panel：这一块你有没有主动打开过滤面板（true/false）。
- expanded：从折叠区点开过几条（0–3 整数）。
- restored：把隐藏/折叠的条目恢复显示过几条（0–3 整数）。
- pref_changes：改过几次标签策略/阈值（0–3 整数）。
- notes：一句话，写你这一块最直接的感受或疑问（可以是"没注意到差别"）。

## 输出 JSON 格式（严格按此，不要加别的字段）

~~~~json
{
  "participant": "P01",
  "persona": "一句话人格名",
  "blocks": [
    {
      "block": 1,
      "study_id": "P01-1-A",
      "condition": "A",
      "video": "BV1Ho4y1D7Wz",
      "genre": "information",
      "density": "high",
      "familiar": 1,
      "discomfort_1": 4, "discomfort_2": 3, "discomfort_3": 4, "discomfort_4": 3, "discomfort_5": 4,
      "coview_1": 5, "coview_2": 5, "coview_3": 5,
      "control_1": 3, "control_2": 3, "control_3": 3,
      "fomo": 4,
      "nasa_1": 3, "nasa_2": 2, "nasa_3": 3, "nasa_4": 5, "nasa_5": 3, "nasa_6": 3,
      "comp_1": 5, "comp_2": 5, "comp_3": 5, "comp_4": 4, "comp_5": 4,
      "recall": "看起来是在讲……，具体内容记不清。",
      "explain_reason": null,
      "explain_clarity": null,
      "explain_example": "",
      "overall_1": 5, "overall_2": 5,
      "opened_panel": false, "expanded": 0, "restored": 0, "pref_changes": 0,
      "notes": "……"
    }
  ]
}
~~~~

- study_id、video、condition、genre、density、block 必须与 index.json 完全一致（照抄）。
- 所有 *_1..*_n 必须是 1–7 的整数。
- C 条件才填 explain_*；A/B 条件 explain_reason/explain_clarity 为 null，explain_example 为空字符串。

## 完成后

1. 自查：6 个块都在、字段齐全、没有 null 混进 1–7 的题。
2. 写文件：out/<你的编号>.json（UTF-8）。
3. 用一句话回复主试：完成 6 块、文件路径、以及你觉得最明显的一个模式。
